1

הורד את הקובץ מהפיס

היכנס לאתר מפעל הפיס → ארכיון תוצאות לוטו → הורד את קובץ ה-CSV המלא.

2

טען את הקובץ כאן

הקובץ נקרא במכשיר שלך בלבד ואינו נשלח לשום מקום.

3

הורד קובץ מעודכן להעלאה לאתר

נוצר קובץ HTML שלם עם הנתונים החדשים בפנים. העלה אותו לגיטהאב בשם index.html וכל המבקרים יראו את העדכון.

שים לב: טעינת הקובץ מעדכנת את התצוגה במכשיר זה בלבד. כדי שהעדכון יופיע אצל כל המשתמשים באתר, יש להוריד את הקובץ בשלב 3 ולהעלות אותו לגיטהאב.
